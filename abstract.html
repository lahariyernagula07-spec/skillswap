SKILLSWAP

ABSTRACT

SkillSwap is a web-based campus platform designed to help students exchange skills with one another. Students can share skills they already know and connect with peers who want to learn those skills, creating a collaborative learning environment within the campus.

The frontend prototype allows users to explore available skills, search and filter listings, view suggested matches, send skill-exchange requests, and access profile, dashboard, session, chat, leaderboard, and SkillPoints interface elements. The platform is intended to encourage peer-to-peer learning, teamwork, and knowledge sharing among students.

The current version demonstrates the user interface using sample data. Backend integration, database storage, authentication, real-time messaging, and production-ready matching are planned as future enhancements.
